# Privacy Policy

**Effective Date:** April 2026
**Project:** New York Chronicles — Custom MTA:SA Client & Launcher

## Overview

New York Chronicles respects user privacy. This document describes what data is collected by the client software and how it is used.

## Data Collected

### MTA Serial
- The MTA serial is a unique identifier generated by the MTA:SA engine
- It is used for account identification and anti-cheat enforcement
- It is **not** derived from hardware components and cannot be used to identify a physical device

### IP Address
- Your IP address is logged when connecting to the game server
- Used for: connection routing, rate limiting, abuse prevention
- Stored on the game server and not shared with third parties

### Game Data
- In-game actions, chat messages, and gameplay statistics are logged for moderation purposes
- This data is associated with your game account, not your real identity

## Data NOT Collected

- **No hardware fingerprinting** — we do not collect disk serials, motherboard IDs, BIOS data, CPU IDs, or any hardware identifiers
- **No personal information** — the client does not access contacts, files, browsing history, or any data outside the game directory
- **No telemetry** — no usage analytics, crash reports, or behavioral data is sent to external services
- **No keylogging** — the client does not monitor keyboard input outside of the game

## Data Storage

- Account data is stored on servers located in Frankfurt, Germany
- Data is protected by encrypted connections (TLS 1.2/1.3)
- Access to server infrastructure is restricted to project administrators via VPN

## Data Deletion

Players may request deletion of their account and associated data by contacting an administrator through the [forum](https://forum.newyorkchronicles.online) or [Discord](https://discord.newyorkchronicles.online).

## Third-Party Services

- **Discord** — used for authentication (OAuth) and community communication
- **Cloudflare** — used for CDN and DDoS protection

No user data is sold or shared with advertisers.

## Changes

This policy may be updated as the project evolves. Changes will be posted to the repository and announced on Discord.

## Contact

For privacy-related questions, contact the project maintainer at [Discord](https://discord.newyorkchronicles.online) or via the [forum](https://forum.newyorkchronicles.online).
